# 심화 통계 핵심 페이지 개선 설계

## 범위

- 대상 페이지
  - `알고리즘 기법 분석`
  - `회귀 통계 분석`
  - `궁합도 분석`
- 이번 작업은 데이터 계산식 자체를 바꾸지 않고, 해석 가능성과 선택 유도력을 높이는 UI/문구 개선에 집중한다.

## 문제 정의

- 현재 3개 페이지 모두 지표 결과는 노출되지만, 사용자가 `그래서 무엇을 보면 되는지`를 빠르게 파악하기 어렵다.
- 필터 기준은 일부 페이지에서만 드러나고, 용어 설명과 해석 가이드가 약해 숫자 카드가 먼저 보인다.
- 실사용 관점에서 `어떤 번호를 참고할지`, `왜 중요한지`가 상단 요약에 정리되어 있지 않다.

## 목표

- 각 페이지 상단에서 현재 분석 기준과 핵심 해석 포인트를 먼저 보여준다.
- 상세 리스트를 보기 전에 사용자가 `이 페이지의 결론`을 3초 안에 이해할 수 있게 만든다.
- 패턴 조합 생성기와 연결되는 페이지는 행동 유도 문구를 명확하게 정리한다.

## 페이지별 설계

### 1. 알고리즘 기법 분석

- 현재 필터 기준 카드는 유지하되, 가독성을 높인다.
- `핫 번호`, `콜드 번호` 카드에는 단순 출현 횟수 외에 `현재 필터 범위 기준`이라는 보조 문구를 넣는다.
- 상단에 짧은 해석 배너를 추가한다.
  - 예: `핫 번호는 최근 범위에서 자주 나온 번호, 콜드 번호는 상대적으로 덜 나온 번호입니다.`
- 하단 설명 영역은 줄이고, `패턴 조합 생성기에서 활용` 카드만 남긴다.
- 생성기로 이동하는 CTA는 유지하되, 왜 이동해야 하는지 한 줄 근거를 붙인다.

### 2. 회귀 통계 분석

- 상단 요약 카드 3개를 추가한다.
  - `평균보다 많이 밀린 번호 수`
  - `가장 많이 밀린 번호`
  - `가장 안정적인 번호`
- 현재의 `출현 임계값 도달 번호` 카드는 유지하되 제목을 쉬운 문구로 바꾼다.
  - 예: `평균보다 오래 안 나온 번호`
- 상세 리스트는 한 줄에서 아래 항목이 모두 비교되게 정리한다.
  - 현재 미출현 회차
  - 평균 회귀 주기
  - 평균 대비 차이
  - 표준편차
- 우측 또는 하단 가이드 카드에서는 `회귀`를 다음처럼 설명한다.
  - `회귀는 번호가 다시 출현하기까지의 평균 간격을 보는 지표이며, 예측이 아니라 참고 흐름입니다.`

### 3. 궁합도 분석

- 선택 전 상태에서도 `전체 Top 조합`과 `사용 가이드`가 함께 보여야 한다.
- 번호 선택 후 상단에 `선택 번호 요약` 카드를 추가한다.
  - 선택 번호
  - 가장 자주 같이 나온 파트너
  - 상위 파트너 평균 동반 출현 횟수
- `BEST 1~10` 카드에는 순위만이 아니라 `선택 번호와의 관계`를 더 쉽게 읽을 수 있도록 문구를 줄인다.
- 전체 Top 10 조합 영역은 유지하되, `전체 기준` 배지를 넣어 선택 번호 기준 결과와 구분한다.

## 공통 원칙

- `현재 분석 기준`은 가능한 한 상단에 둔다.
- 전문 용어는 그대로 쓰더라도 바로 아래에 쉬운 해석 문장을 붙인다.
- 빈 상태와 첫 진입 상태는 `무엇을 해야 하는지`가 드러나도록 바꾼다.
- 기존 계산 API와 필터 구조는 유지한다.

## 검증 계획

- 대상 3개 페이지의 변경 파일에 대해 ESLint를 실행한다.
- 수동 확인 포인트
  - 필터 적용 전/후 빈 상태 문구 확인
  - 모바일에서 상단 요약 카드 줄바꿈 확인
  - 알고리즘 페이지 CTA가 패턴 조합 생성기로 정상 이동하는지 확인

## 제외 범위

- 다른 심화 통계 페이지 일괄 개편
- 통계 계산 로직 변경
- 새로운 서버 API 추가
