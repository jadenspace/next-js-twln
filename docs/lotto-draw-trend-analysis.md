# 당첨번호 추이분석 가이드

## 목적

`당첨번호 추이분석`은 각 회차의 당첨번호를 한 줄씩 펼쳐서 패턴 변화를 빠르게 확인하는 관리자용 화면이다.

이 화면은 아래 질문에 답하기 위해 사용한다.

- 이번 회차는 최근 회차와 얼마나 겹쳤는가
- 번호 구성이 평소보다 몰려 있는가
- 홀짝, 고저, AC, 연번 패턴이 극단적인가
- 동일끝수나 동일구간이 강하게 나타났는가

## 테이블 컬럼 정의

### 기본 정보

- `회차`: 추첨 회차 번호
- `추첨일`: 해당 회차의 추첨 날짜
- `당첨번호`: 메인 번호 6개
- `보너스`: 보너스 번호 1개

### 패턴 지표

- `홀짝`: 메인 번호 6개 중 홀수:짝수 비율
  - 예: `3:3`, `4:2`
- `고저`: 저번호:고번호 비율
  - 저번호는 `1~22`
  - 고번호는 `23~45`
- `합계`: 메인 번호 6개의 합
- `AC`: 번호 간 차이값의 다양성 지표
  - 낮을수록 번호 간격 패턴이 단순하고 몰려 있을 가능성이 높다
- `연번`: 정렬된 번호 기준으로 연속된 번호 쌍의 개수
  - 예: `10, 11`은 연번 1개
- `동일끝수`: 끝자리가 같은 번호가 가장 많이 겹친 개수
  - 예: `8, 18, 28`이 있으면 `3`
- `동일구간`: 5개 단위 구간에서 가장 많이 겹친 개수
  - 구간 기준: `1-5`, `6-10`, `11-15`, `16-20`, `21-25`, `26-30`, `31-35`, `36-40`, `41-45`
  - 예: `8, 10`은 `6-10` 구간에 2개이므로 `2`

### 회귀 지표

- `전회차회귀`: 직전 1개 회차 메인번호와 겹치는 개수
- `지난3회차회귀`: 최근 3개 회차 메인번호 전체와 겹치는 개수
- `지난6회차회귀`: 최근 6개 회차 메인번호 전체와 겹치는 개수
- `지난10회차회귀`: 최근 10개 회차 메인번호 전체와 겹치는 개수
- `전회차보너스회귀`: 직전 회차 보너스번호가 현재 메인번호에 포함되는 개수

## 상태 정의

화면의 `상태`는 운영자가 회차를 빨리 분류하기 위한 요약 라벨이다.

### `일반`

아래 조건에 해당하지 않는 기본 상태다.

### `회귀`

아래 조건을 만족하면 `회귀`로 본다.

- `지난3회차회귀 > 0`

즉, 최근 3개 회차 안의 메인번호와 현재 회차가 하나 이상 겹치면 `회귀` 상태다.

### `이상치`

아래 조건 중 하나라도 만족하면 `이상치`로 표시한다.

- `전회차회귀 >= 3`
- `지난3회차회귀 >= 4`
- `AC <= 4`
- `홀짝 = 6:0`
- `홀짝 = 0:6`

즉, `이상치`는 에러가 아니라 `평소보다 눈에 띄는 패턴을 가진 회차`를 뜻한다.

운영상 해석은 다음처럼 보면 된다.

- `전회차회귀 >= 3`
  - 직전 회차와 너무 많이 겹침
  - 강한 반복 성향
- `지난3회차회귀 >= 4`
  - 최근 흐름에 번호가 강하게 집중됨
- `AC <= 4`
  - 번호 간격 구조가 단순함
  - 패턴이 퍼져 있기보다 몰려 있을 가능성이 높음
- `홀짝 6:0 또는 0:6`
  - 홀짝 구성이 극단적임

## 강조 규칙

현재 화면에서 추가 강조하는 규칙은 아래와 같다.

- `동일끝수 >= 3`이면 강조
- `동일구간 >= 3`이면 강조
- `전회차회귀 >= 3`이면 강조
- `지난3회차회귀 >= 4`이면 강조

## 예시 해석

예를 들어 어떤 회차가 아래와 같다고 가정한다.

- 홀짝: `3:3`
- AC: `7`
- 동일끝수: `2`
- 동일구간: `2`
- 전회차회귀: `2`
- 지난3회차회귀: `2`
- 지난6회차회귀: `4`
- 지난10회차회귀: `5`

이 경우 해석은 다음과 같다.

- 홀짝과 AC는 극단값이 아님
- 직전 회차 반복은 보통 수준
- 다만 최근 6회, 10회 범위로 넓히면 중복이 제법 많은 편
- 즉, 직전 회차 집중형은 아니지만 최근 흐름 재등장 성향은 있는 회차로 볼 수 있음

## 상세 모달 해석

상세 모달은 아래 순서로 보면 된다.

1. `현재 회차 번호`
   - 최근 10회차 안에서 회귀된 번호는 강조 표시
2. `상단 패턴 카드`
   - 홀짝, 고저, 합계, AC, 연번, 동일끝수, 동일구간을 빠르게 확인
3. `회귀 범위별 번호`
   - 어느 범위에서 어떤 번호가 실제로 겹쳤는지 확인
4. `패턴 수치 요약`
   - 운영자가 수치만 빠르게 스캔할 때 사용

## 주의사항

- `이상치`는 오류 데이터가 아니라 운영상 눈에 띄는 회차라는 뜻이다
- `지난10회차회귀`가 높다고 해서 반드시 특이 회차는 아니다
  - 최근 범위를 넓게 잡을수록 중복 개수는 자연스럽게 증가할 수 있다
- `동일끝수`, `동일구간`은 “패턴 밀집도”를 보는 보조 지표이지 단독 판단 기준은 아니다
